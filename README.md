# VimAura International — website

React + TypeScript + Vite, animated with GSAP ScrollTrigger (+ MotionPathPlugin) and Lenis smooth scrolling.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/ (relative paths, host anywhere)
```

## Structure
- `src/components/` — one component per section (Navbar, HeroSection, AnimatedBook, PaperAirplane, AboutSection, ServicesSection, GermanSection, UpcomingLanguages, GlobalJourney, ContactSection, Footer) with colocated CSS.
- `src/components/illustrations/` — custom SVG artwork. `worldDots.ts` is generated by `scripts/gen-map.mjs` from Natural Earth data (`node scripts/gen-map.mjs`).
- `src/lib/contact.ts` — all contact details, WhatsApp link and nav items in one place.
- `src/lib/gsap.ts`, `src/lib/smoothScroll.ts`, `src/lib/useReveal.ts` — animation setup.
- `src/assets/logo.png` — the original logo, displayed unaltered.

## Motion notes
- All scroll animations are scrubbed, so they reverse when scrolling up.
- `prefers-reduced-motion: reduce` disables Lenis, pins and scroll choreography; every section renders in its final, readable state.
